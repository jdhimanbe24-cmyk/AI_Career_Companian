ROLE: Data Scientist

ROLE DESCRIPTION:
A Data Scientist collects, analyzes and interprets data to generate
insights, build predictive models and support data-driven decision
making.

EDUCATION:
Typical candidates have a degree in Computer Science, Computer
Engineering, Information Technology, Data Science, Statistics,
Mathematics, Artificial Intelligence or a related technical field.

PROJECT EXPECTATIONS:
Candidates should ideally have 2 or more relevant technical projects.

Relevant projects include:
Predictive analytics applications
Machine Learning applications
Data analysis projects
Customer segmentation projects
Recommendation systems
Time series forecasting projects
NLP applications
Business intelligence projects
Data visualization projects
End-to-end data science projects

PROJECT QUALITY:
Projects should explain the problem solved, dataset used,
technologies used, candidate's contribution, data preprocessing,
analysis, model implementation, evaluation metrics and measurable
results where possible.

CERTIFICATIONS:
Relevant certifications in:
Data Science
Machine Learning
Python
Statistics
SQL
Artificial Intelligence
Cloud Computing
Power BI
Tableau

Certifications are beneficial but are not always mandatory.

EXPERIENCE:
Internships, research experience, freelance projects or relevant
industry experience are beneficial.

ENTRY LEVEL:
For entry-level candidates, strong data science projects,
demonstrated statistical knowledge and practical machine learning
experience can partially compensate for lack of professional
experience.
