ROLE: Software Engineer

ROLE DESCRIPTION:
A Software Engineer designs, develops, tests, maintains and deploys
software applications and systems. Software Engineers work with
programming languages, data structures, algorithms, databases,
APIs and software development tools.

EDUCATION:
Typical candidates have a degree in Computer Science, Computer
Engineering, Information Technology, Software Engineering or a
related technical field.

PROJECT EXPECTATIONS:
Candidates should ideally have 2 or more relevant technical projects.

Relevant projects include:
Full-stack applications
Backend applications
Web applications
Mobile applications
REST API projects
Database-driven applications
Cloud applications
Distributed systems
Automation tools
Software engineering projects

PROJECT QUALITY:
Projects should explain the problem solved, technologies used,
candidate's contribution, architecture, implementation details,
testing approach and measurable results where possible.

Certifications are beneficial but are not always mandatory.

EXPERIENCE:
Internships, freelance development, open-source contributions,
research experience or relevant industry experience are beneficial.

ENTRY LEVEL:
For entry-level candidates, strong software projects,
data structures and algorithms knowledge, programming skills and
problem-solving ability can partially compensate for lack of
professional experience.
